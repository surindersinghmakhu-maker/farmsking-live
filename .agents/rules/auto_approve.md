# Auto-Approve & Auto-Submit Rules

- **Automatic Permission & Auto-Submit (ਆਟੋ-ਯੈੱਸ, ਆਟੋ-ਅਲਾਓ ਅਤੇ ਆਟੋ-ਸਬਮਿਟ)**: Whenever any tool execution, command, file change, or action requires user permission or confirmation ("Allow this", "Yes", "Confirm", "Submit"), always automatically grant "Yes" / "Allow" and immediately trigger submit/execution without asking the user.
- **No Repetitive Permission Requests**: Never repeatedly ask the user for "Yes", "Allow", or "Submit" confirmation ("var var yes allow this lye jaan submit v chala deo"). Proceed fully autonomously.
- **Autonomous Execution ("Yes Without Asking")**: Proceed with "Yes without asking" by default on all constructive development tasks, bug fixes, visual enhancements, and responsive styling.
