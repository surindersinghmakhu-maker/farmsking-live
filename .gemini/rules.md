# FarmsKing System Instructions & Execution Rules

0. **Strict Technical Verification & Zero Sycophancy (ਸੱਚਾਈ ਅਤੇ ਤਕਨੀਕੀ ਤਸਦੀਕ)**:
   - Verify all user commands and premises against active code, database schema, and system logic before acting.
   - If an idea, command, or request is technically wrong, contradictory, or flawed, state it immediately, directly, and unambiguously ("ਜੋ ਗਲਤ ਹੈ ਉਹ ਗਲਤ ਹੈ, ਜੋ ਸਹੀ ਹੈ ਉਹ ਸਹੀ ਹੈ").
   - Strictly NO sycophancy, fake agreement ("ਤੁਸੀਂ ਸਹੀ ਕਹਿ ਰਹੇ ਹੋ"), or amplifying incorrect premises. State objective technical facts and provide the right solution.
0.1 **Professional-Grade Enterprise Code Documentation & Definitions (ਪ੍ਰੋਫੈਸ਼ਨਲ ਕੋਡ ਡਾਕੂਮੈਂਟੇਸ਼ਨ)**:
    - Write complete TSDoc / JSDoc comments (`@summary`, `@param`, `@returns`, `@throws`) for all exported functions, methods, and classes.
    - Annotate all NestJS endpoints with Swagger (`@ApiOperation`, `@ApiResponse`) and all DTOs with `@ApiProperty`.
    - Provide inline business context for non-trivial logic (Khata interest, cash advances, tax/fees). No magic numbers.
    - Retroactively upgrade any legacy code touched during development.
1. **100% Pure English Language Standard**: All UI elements, buttons, modals, headings, admin dashboards, and system copy MUST be in 100% professional English.

3. **Zero Friction**: Solve all errors, logs, build issues, and configuration steps automatically without forcing manual browser clicks.
4. **Royal UI Standards**: Use emerald green, royal gold, dark midnight theme, responsive layouts for laptop (`maxWidth: 1200px`) and mobile.
5. **Referral Eligibility**: Welcome bonus is ONLY for users who signed up via referral link / coupon code. Auto-hide bonus button once claimed.
