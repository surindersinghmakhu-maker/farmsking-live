<a name="sec-1"></a>
### 1. 🎓 ਖੇਤੀਬਾੜੀ ਸਲਾਹਕਾਰ ਬਣਨ ਦਾ ਤਰੀਕਾ
- ਐਪ ਵਿੱਚ **'ਮੇਰੀ ਪ੍ਰੋਫਾਈਲ'** ਵਿੱਚ ਜਾ ਕੇ **Farm Advisor / Garden Advisor** ਚੁਣੋ।
- ਆਪਣਾ ਮੋਬਾਈਲ ਨੰਬਰ, ਪਿੰਡ ਅਤੇ ਡਿਗਰੀ/ਤਜਰਬਾ ਦਰਜ ਕਰੋ।
- ਤੁਹਾਡੀ **Advisor King ID** ਤੁਰੰਤ ਚਾਲੂ ਹੋ ਜਾਵੇਗੀ।

---

<a name="sec-2"></a>
### 2. 📱 ਕਿਸਾਨਾਂ ਨੂੰ ਕੂਪਨ ਭੇਜਣ ਦਾ ਤਰੀਕਾ
- ਐਪ ਵਿੱਚ **'ਕੂਪਨ ਪ੍ਰਬੰਧਨ' (Coupons)** ਵਿੱਚ ਜਾਓ।
- ਕਿਸਾਨ ਲਈ PRO ਜਾਂ SMART ਪਲੈਨ ਦਾ ਕੂਪਨ ਕੋਡ ਬਣਾਓ।
- **WhatsApp Share** ਬਟਨ ਦਬਾ ਕੇ ਕਿਸਾਨ ਦੋਸਤ ਨੂੰ ਭੇਜੋ।

---

<a name="sec-3"></a>
### 3. 💰 ਕਮਾਈ ਅਤੇ ਵਾਲਿਟ ਇਨਕਮ (₹150 - ₹300 ਪ੍ਰਤੀ ਕਿਸਾਨ)
- ਜਦੋਂ ਕਿਸਾਨ ਤੁਹਾਡਾ ਕੂਪਨ ਵਰਤ ਕੇ ਐਪ ਚਾਲੂ ਕਰੇਗਾ, ਤੁਹਾਨੂੰ **₹150 ਤੋਂ ₹300 ਦੀ ਤੁਰੰਤ ਕਮਾਈ** ਵਾਲਿਟ ਵਿੱਚ ਮਿਲੇਗੀ।
- ਵਾਲਿਟ ਵਿੱਚੋਂ ਪੈਸੇ 1-ਕਲਿੱਕ ਵਿੱਚ ਆਪਣੇ ਬੈਂਕ ਜਾਂ UPI ਵਿੱਚ ਟ੍ਰਾਂਸਫਰ ਕਰੋ।

---

<a name="sec-4"></a>
### 4. 👨‍🌾 ਕਿਸਾਨਾਂ ਨੂੰ ਖੇਤੀਬਾੜੀ ਸਲਾਹ ਦੇਣ ਦਾ ਤਰੀਕਾ
- ਐਪ ਵਿੱਚ **'ਚੈਟ' (Chat)** ਵਾਲੀ ਆਪਸ਼ਨ ਦਬਾਓ।
- ਕਿਸਾਨ ਦੁਆਰਾ ਭੇਜੀ ਫਸਲ ਦੇ ਪੱਤੇ ਦੀ ਫੋਟੋ ਦੇਖ ਕੇ ਸਹੀ ਦਵਾਈ ਅਤੇ ਸਪਰੇਅ ਦਾ ਸੁਝਾਅ ਦਿਓ।
