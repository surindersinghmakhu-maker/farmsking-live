🌾 FarmsKing Category Architecture & Dynamic Admin Toggle Guide

ਪ੍ਰੋਜੈਕਟ ਸ਼੍ਰੇਣੀ ਵੰਡ, ਆਜ਼ਾਦ ਮੋਡਿਊਲ ਡਿਜ਼ਾਇਨ (Decoupled Architecture) ਅਤੇ ਐਡਮਿਨ ਆਨ/ਓਫ (Category & Sub-Category Toggle) ਸਿਸਟਮ ਗਾਈਡ

Architecture & Feature Flags Manual • 2026
1. FarmsKing ਦੀਆਂ 8 ਮੁੱਖ Categories ਅਤੇ Sub-Categories ਦੀ ਪੂਰੀ ਵੰਡ
1. 👤 User Accounts & Auth Domain Category Key: user_accounts

ਯੂਜ਼ਰ ਲੌਗਇਨ, ਰਜਿਸਟ੍ਰੇਸ਼ਨ, ਸੁਰੱਖਿਆ ਅਤੇ ਐਡਰੈੱਸ ਪ੍ਰਬੰਧਨ।

  • Authentication (auth): OTP ਲੌਗਇਨ, ਰਿਫ੍ਰੈਸ਼ ਟੋਕਨ, JWT ਵੈਰੀਫਿਕੇਸ਼ਨ।
  • User Profile (users): ਕਿਸਾਨ/ਐਡਵਾਈਜ਼ਰ/ਵਰਕਰ ਪ੍ਰੋਫਾਈਲ, King ID ਤਿਆਰੀ।
  • Address Book (addresses): ਪਿੰਡ, ਜ਼ਿਲ੍ਹਾ, ਪਿਨਕੋਡ ਅਤੇ ਡਿਲੀਵਰੀ ਪਤੇ।
  • Audit & Security (audit): ਲੌਗਇਨ ਹਿਸਟਰੀ, ਐਕਟੀਵਿਟੀ ਟ੍ਰੈਕਿੰਗ।
  • Uploads System (uploads): ਪ੍ਰੋਫਾਈਲ ਅਤੇ ਡੌਕੂਮੈਂਟ ਅਪਲੋਡਜ਼।
2. 🌾 Farmer & Agriculture Domain Category Key: farmer_operations

ਕਿਸਾਨ ਦੀਆਂ ਫਸਲਾਂ, ਖੇਤ, ਸਪਰੇਅ ਅਤੇ ਹਿਸਾਬ-ਕਿਤਾਬ।

  • Farms & Plots (farms / plots): ਖੇਤਾਂ ਅਤੇ ਪਲਾਟਾਂ ਦਾ ਏਕੜ ਰਿਕਾਰਡ।
  • Crops Management (crops): ਐਕਟਿਵ ਫਸਲਾਂ ਅਤੇ ਬੀਜਣ ਦੀਆਂ ਤਰੀਕਾਂ।
  • Crop Problems (crop-problems): ਫਸਲ ਦੀਆਂ ਬੀਮਾਰੀਆਂ ਤੇ ਕੀੜਿਆਂ ਦੀ ਪਛਾਣ।
  • Spray Schedules (spray-schedules): ਛਿੜਕਾਅ ਦੀਆਂ ਤਰੀਕਾਂ ਅਤੇ ਖਾਦ ਰਿਕਾਰਡ।
  • Labour & Expenses (labour / expenses): ਮਜ਼ਦੂਰੀ ਦੀ ਹਾਜ਼ਰੀ, ਦਿਹਾੜੀ ਤੇ ਖੇਤ ਦੇ ਖਰਚੇ।
3. 🛒 Shopping & E-Commerce Domain Category Key: shopping

ਪ੍ਰੋਡਕਟ ਲਿਸਟਿੰਗ, ਆਰਡਰ ਪ੍ਰਬੰਧਨ ਅਤੇ ਵਿਕਰੀ ਬਿੱਲ।

  • Products Catalog (products): ਖਾਦ, ਬੀਜ, ਦਵਾਈਆਂ ਤੇ ਔਜ਼ਾਰ।
  • Orders Management (orders): ਕਾਰਟ, ਚੈੱਕਆਊਟ, ਆਰਡਰ ਸਟੇਟਸ (Pending, Shipped, Delivered)।
  • Sale Bills (sale-bills): ਕਿਸਾਨਾਂ ਦੁਆਰਾ ਵੇਚੀਆਂ ਫਸਲਾਂ ਦੇ ਡਿਜੀਟਲ ਬਿੱਲ।
  • Parties Ledger (parties): ਆੜ੍ਹਤੀ, ਦੁਕਾਨਦਾਰ ਅਤੇ ਖਰੀਦਦਾਰਾਂ ਦਾ ਖਾਤਾ।
  • Payment Receipts (payment-receipts): ਪ੍ਰਾਪਤ ਪੈਸਿਆਂ ਦੀਆਂ ਡਿਜੀਟਲ ਰਸੀਦਾਂ।
4. 👨‍🌾 Advisor & Support Domain Category Key: advisor_support

ਖੇਤੀ ਮਾਹਿਰਾਂ ਨਾਲ ਰਾਬਤਾ ਅਤੇ ਸਲਾਹਕਾਰੀ।

  • Advisor Assignment (advisor-assignment): ਕਿਸਾਨ ਨੂੰ ਸਹੀ ਐਡਵਾਈਜ਼ਰ ਅਲੋਟ ਕਰਨਾ।
  • Advisor Chat (chat): ਫੋਟੋਆਂ ਤੇ ਮੈਸੇਜ ਭੇਜ ਕੇ ਫਸਲ ਦੀ ਸਲਾਹ ਲੈਣਾ।
  • Call Requests (call-requests): ਫੋਨ ਕਾਲ ਲਈ ਰਿਕਵੈਸਟ ਬਟਨ।
  • Admin Support Chat (admin-chat): 24x7 ਐਡਮਿਨ ਹੈਲਪਲਾਈਨ।
5. 💳 Coupons, Plans & Financial Domain Category Key: coupons_financial

ਪਲਾਨ, ਕੂਪਨ ਡਿਸਕਾਊਂਟ, ਵਾਲੇਟ ਅਤੇ ਪੇਮੈਂਟਸ।

  • Coupons System (coupons / coupon-settings): ਪ੍ਰੋਮੋ ਕੋਡ ਅਤੇ ਡਿਸਕਾਊਂਟ ਰੂਲਜ਼।
  • Subscription Plans (farmer-plans / gardener-plans): Free, Lite, Pro, Smart ਪਲਾਨ।
  • Plan Payments & Renewal (plan-payments / plan-renewal): ਪਲਾਨ ਰੀਨਿਊ ਅਤੇ UPI QR Payment।
  • Wallet & Withdrawals (wallet / withdrawals): ਕਿਸਾਨ/ਐਡਵਾਈਜ਼ਰ ਵਾਲੇਟ ਅਤੇ ਪੈਸੇ ਕਢਵਾਉਣਾ।
  • Payment Gateway (phonepe): PhonePe ਆਨਲਾਈਨ ਭੁਗਤਾਨ ਇੰਟੀਗ੍ਰੇਸ਼ਨ।
6. 📞 Telephony & Communication Domain Category Key: telephony_comm

ਆਡੀਓ ਕਾਲਿੰਗ, ਵਟਸਐਪ ਆਟੋਮੇਸ਼ਨ ਤੇ ਨੋਟੀਫਿਕੇਸ਼ਨ।

  • WhatsApp System (whatsapp): ਬਿੱਲ, ਅਲਰਟ ਤੇ ਮੈਸੇਜ ਵਟਸਐਪ 'ਤੇ ਭੇਜਣਾ।
  • Voice Call (voice-call): ਐਪ ਅੰਦਰ ਇੰਟਰਨੈੱਟ/ਸਿਮ ਰਾਹੀਂ ਆਡੀਓ ਕਾਲਿੰਗ।
  • Voice AI (voice-ai): ਆਟੋਮੇਟਿਡ AI ਆਡੀਓ ਸੁਨੇਹੇ।
  • Push Notifications (notifications): ਮੋਬਾਈਲ ਪੁਸ਼ ਨੋਟੀਫਿਕੇਸ਼ਨਜ਼।
7. 🌤️ Weather & Satellite Intelligence Category Key: weather_intelligence

ਮੌਸਮ, ਸੈਟੇਲਾਇਟ ਫਸਲ ਨਿਗਰਾਨੀ ਅਤੇ ਮੰਡੀ ਭਾਅ।

  • Live Weather (weather): ਤਾਪਮਾਨ, ਬਾਰਿਸ਼ ਤੇ ਮੌਸਮੀ ਚੇਤਾਵਨੀਆਂ।
  • Satellite Crop Monitoring (satellite): ਖੇਤ ਦਾ ਸੈਟੇਲਾਇਟ ਮੈਪ ਤੇ ਫਸਲ ਦੀ ਸਿਹਤ (NDVI)।
  • Mandi AI & Rates (mandi-ai / market-rates): ਲਾਈਵ ਮੰਡੀ ਰੇਟ ਅਤੇ ਕੀਮਤ ਦਾ ਅਨੁਮਾਨ।
8. ⚙️ System & Infrastructure Domain Category Key: system_infra

ਐਪ ਸੈਟਿੰਗਜ਼, ਬੈਕਅੱਪ ਤੇ ਐਡਮਿਨ ਕੰਟਰੋਲ।

  • App Settings (app-settings): ਗਲੋਬਲ ਕੌਨਫਿਗ੍ਰੇਸ਼ਨ ਅਤੇ ਮੋਡਿਊਲ ਟੌਗਲਜ਼।
  • Drive Backup (google-drive-backup): ਡਾਟਾਬੇਸ ਦਾ ਆਟੋਮੈਟਿਕ ਬੈਕਅੱਪ।
  • Referral System (referrals): ਦੋਸਤਾਂ ਨੂੰ ਐਪ ਰੈਫਰ ਕਰਕੇ ਇਨਾਮ ਜਿੱਤਣਾ।
2. Admin Panel ਵਿੱਚ Dynamic Toggle (ON/OFF) ਸਿਸਟਮ ਕਿਵੇਂ ਕੰਮ ਕਰੇਗਾ?

ਐਡਮਿਨ ਪੈਨਲ ਵਿੱਚ ਕਿਸੇ ਵੀ Main Category ਜਾਂ Sub-Category ਨੂੰ Dynamic ON/OFF ਕਰਨ ਲਈ 3 ਲੇਅਰਾਂ (Database, Backend Guard, Frontend Dynamic UI) ਦਾ ਡਿਜ਼ਾਇਨ ਤਿਆਰ ਕੀਤਾ ਗਿਆ ਹੈ:

Step 1: Database Feature Flag JSON Schema

ਡਾਟਾਬੇਸ ਦੇ AppSetting ਟੇਬਲ ਵਿੱਚ ਹਰੇਕ ਕੈਟੇਗਰੀ ਅਤੇ ਸਬ-ਕੈਟੇਗਰੀ ਦੀ ਸਟੇਟਸ ਫਲੈਗ (Status Flag) ਰੱਖੀ ਜਾਵੇਗੀ:

{ "featureFlags": { "shopping": { "enabled": true, "subCategories": { "products": true, "orders": true, "saleBills": false, // Admin toggled OFF "parties": true } }, "telephony_comm": { "enabled": true, "subCategories": { "whatsapp": true, "voiceCall": false, // Admin toggled OFF "voiceAi": false } } } }

Step 2: Backend (NestJS) Route Protection Guard

ਜੇਕਰ ਐਡਮਿਨ ਨੇ ਕੋਈ ਕੈਟੇਗਰੀ ਬੰਦ ਕੀਤੀ ਹੋਵੇਗੀ, ਤਾਂ Backend API ਤੁਰੰਤ 403 Service Disabled ਦਾ ਰਿਸਪੌਂਸ ਦੇਵੇਗਾ ਤਾਂ ਜੋ ਕੋਈ ਡਾਇਰੈਕਟ API ਕਾਲ ਵੀ ਨਾ ਕਰ ਸਕੇ:

// Controller Route Protection Example @UseGuards(FeatureFlagGuard) @RequireFeature('shopping', 'saleBills') @Post('create-bill') async createSaleBill(@Body() dto: CreateBillDto) { return this.saleBillsService.create(dto); }

Step 3: Frontend (React / Mobile App) Dynamic UI Hiding

ਫਰੰਟਐਂਡ useFeatureFlags() ਹੁੱਕ ਜ਼ਰੀਏ ਸੈਟਿੰਗਜ਼ ਰੀਡ ਕਰੇਗਾ। ਜੇਕਰ ਕੋਈ ਕੈਟੇਗਰੀ ਜਾਂ ਸਬ-ਕੈਟੇਗਰੀ OFF ਹੈ:

  • ਉਸਦਾ **Sidebar Menu Item / Tab ਆਟੋਮੈਟਿਕ ਗਾਇਬ (Hide)** ਹੋ ਜਾਵੇਗਾ।
  • ਉਸ ਨਾਲ ਸੰਬੰਧਿਤ ਬਟਨ (ਜਿਵੇਂ Call Advisor ਜਾਂ WhatsApp Share) ਐਪ ਵਿੱਚੋਂ Disappear ਹੋ ਜਾਣਗੇ।
  • ਕੋਈ ਵੀ ਪੇਜ ਖੋਲ੍ਹਣ 'ਤੇ *"ਇਹ ਸੁਵਿਧਾ ਫਿਲਹਾਲ ਐਡਮਿਨ ਦੁਆਰਾ ਬੰਦ ਕੀਤੀ ਗਈ ਹੈ"* ਦਾ ਨੋਟਿਸ ਦਿਖਾਈ ਦੇਵੇਗਾ।

💡 Decoupled Development Rule for Engineers:

ਜਦੋਂ ਵੀ ਕਿਸੇ ਨਵੀਂ ਕੈਟੇਗਰੀ 'ਤੇ ਕੰਮ ਕਰਨਾ ਹੋਵੇ, ਤਾਂ ਉਸ ਕੈਟੇਗਰੀ ਨੂੰ featureFlags JSON ਕੌਨਫਿਗ੍ਰੇਸ਼ਨ ਵਿੱਚ ਰਜਿਸਟਰ ਕਰੋ। ਇਸ ਨਾਲ ਹੋਰ ਸਾਰੇ ਮੋਡਿਊਲਾਂ ਤੋਂ ਬਿਨਾਂ ਛੇੜਛਾੜ ਕੀਤੇ ਉਸ ਕੈਟੇਗਰੀ ਨੂੰ ਐਡਮਿਨ ਪੈਨਲ ਤੋਂ ਲਾਈਵ ਕੰਟਰੋਲ ਕੀਤਾ ਜਾ ਸਕਦਾ ਹੈ।
